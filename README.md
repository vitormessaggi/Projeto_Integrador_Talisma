# Projeto_Integrador Talismã Imóveis
Este repositório é utilizado para o projeto integrador do curso de Análise e Desenvolvimento de sistemas do senai Armando de Arruda Pereira. O projeto, consiste em um sistema completo para a imobiliária Talismã. Contendo: Banco de dados, Site corporativo, APP para Alugueis e venda, Chat Bot e totalmente testado contra ataques.
